Deal Radar adalah situs statis pencari deal Black Friday dan Cyber Monday. Situs ini memuat 26 deal nyata yang dicek pada 27 November 2026 dari Amazon, Best Buy, Walmart, dan Costco, masing-masing lengkap dengan harga sale, harga biasa, persentase diskon, dan penilaian jujur atas tiap harga: new low, strong price, atau routine sale. Jadi pembeli bisa langsung melihat deal mana yang benar-benar murah dan mana yang cuma diskon biasa.

Dibuat untuk bounty [black-friday-deal-finder-01](https://make.fun/bounty/black-friday-deal-finder-01) di [make.fun](https://make.fun).

## Cara menjalankan

Buka `app/index.html` langsung di browser, atau jalankan server statis dari dalam folder `app`:

```bash
npx serve app
```

atau

```bash
cd app
python3 -m http.server
```
